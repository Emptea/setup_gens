# Установка параметров генераторов AFG3102C И DG1022A по usb
Запуск:
```bash
C:/Users/vadmin/AppData/Local/Programs/Python/Python310-32/python.exe d:/work/mini/setup_gens/setup_gens.py
```

Устанавливает AFG3102C в режим генерации синусоидального сигнала частотой 40 МГц, размахом 3 Vpp по обоим каналам, синхронно с внешним тактом 10 МГц.

Устанавливает DG1022A в режим генерации прямоугольного сигнала периодом 46.4 мкс, размахом 3 Vpp на канале 1, синхронно с внешним тактом 10 МГц.

## Известные проблемы
DF1022A может переставать распознаваться, решается перезапуском генератора.
